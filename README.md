# 异人之下站点点赞

**识图点赞助手 1.2**是面向 Windows 10 / 11 的本地桌面程序，用于在“异人之下站点”的“小栈”帖子列表和帖子详情评论区识别空心点赞图标、点击并自动下滑。

## 下载和使用

在 [v1.2 发布页](https://github.com/lihua2233/yiren-zhixia-zhandian-dianzan/releases/tag/v1.2) 下载 **ShituDianzanZhushou.exe**（识图点赞助手）、**Usage.txt**（使用说明）和 **Source.zip**（完整源码）。直接运行 EXE，无需安装 Python。

1. 打开小程序的“小栈”列表，将窗口放到屏幕一侧。
2. 在助手里选择“异人之下站点”和“点赞对象”（帖子/评论，单栏/分栏），点击“预览识别（不点击）”。绿色框应只圈住未点赞心形；不准确时先“框选空心赞”重新校准。
3. 设置本次目标数量和间隔，按需开启自动下滑，再点击“开始”。首次建议将目标设为 1，检查实际效果。
4. 运行时保留置顶进度小窗，显示确认数量、目标、用时、实时速度、预计剩余时间、预计完成时刻和最新状态。保持小程序在前台，避免移动、缩放或遮挡窗口。
5. 按 **F8** 或点击小窗的“停止”随时停止。结束后恢复完整界面与日志。

完整步骤、计数规则和故障处理见 [使用说明](使用说明.txt)。

## 功能

- 评论点赞：支持右侧分栏和单栏评论页，包含已展开回复；独立保存评论校准，排除左侧帖子及底部固定按钮。手动打开帖子并滚动到评论区后使用，不自动展开全部回复或切换帖子。

- 自然操作增加随机落点：点赞在心形中心附近小幅偏移，下滑在列表中部随机选点，同轮三次滚动保持位置不变。关闭自然操作后使用原固定位置。

- 自然操作默认开启：平滑移动、短暂按压、小幅间隔变化和分段滚动；可关闭。下滑前平滑移到滚动位置，随后分三次各滚动一格，保留原总滚动量。移动后重新确认图标，中断按压会释放鼠标。

- 自定义新增点赞目标：1–10000，默认 500。
- 两次点击最小间隔：1.5–30 秒，默认 3 秒。确认与下滑用时计入间隔，减少重复等待。
- 下滑后检测画面变化与稳定；持续变化时停止。
- 确认 5 个后按实测速率动态估算时间，开始前提供粗估范围。
- 本地校准心形图标，识别预览不执行点击。
- 点击后连续两次检测新增红色或橙色像素才计数；彩色的已点赞图标不作为点击候选。
- 可选自动下滑，置顶进度窗自动避开目标窗口。
- 前台窗口变化、遮挡、无法确认变色或连续下滑无变化时停止。

每次开始从 0 计数。计数是界面的视觉确认，并非服务器回执；确认中途停止时，实际点赞数可能多于已确认数。

## 从源码运行

使用 64 位 Windows 和 Python 3.11：

```powershell
python -m pip install -r requirements.txt
python app.py
```

程序自带此前校准的图标，换电脑或更改页面缩放后请重新校准。校准及日志存放于 `%LOCALAPPDATA%\XiaozhanLikeAssistant`。

## 构建 EXE

```powershell
python -m pip install -r requirements-build.txt
./build.ps1
```

也可手动构建：

```powershell
$heartPath = (Resolve-Path ./heart.png).Path
$calibrationPath = (Resolve-Path ./calibration.json).Path
python -m PyInstaller --noconfirm --onefile --windowed --name XiaozhanLikeAssistant --add-data "$heartPath;." --add-data "$calibrationPath;." --add-data "comment_heart.png;." --add-data "comment_calibration.json;." app.py
Copy-Item ./dist/XiaozhanLikeAssistant.exe ./dist/识图点赞助手.exe
```

## 预计用时与账号检测

500 个目标、开启自动下滑：自然操作开启时，默认 3 秒粗估 31–57 分钟；1.5 秒粗估 19–44 分钟。关闭自然操作时分别为 29–42、16–30 分钟。假设与限制详见使用说明，运行中按实测更新。

本程序不具备防检测或防封保证。无提示封禁无法通过屏幕识别提前预警；更快的操作可能增加账号限制风险。

程序仅使用本地截图识别和鼠标操作，不读取账号密码，不上传截图。运行依赖前台窗口，不支持后台、锁屏或遮挡运行。
